# 自动保存与自动恢复是"每文件"开关，互不联动

_Status: accepted_

最初把"自动保存 / 自动恢复"做成了全局开关且默认开启，结果：用户一打开任何文档就被自动覆盖、被自动记快照，既吓人也不符合预期。

改为**每文件状态**：
- 新建或打开文档时，两个开关**都是关的**；
- 状态持久化在两处（`documents.json` 汇总 + 该文档的 `index.json`），下次打开沿用上次的状态；
- 两者**完全独立、无联动**：
  - 只开自动保存 → 定时覆盖原文件，**不产生版本历史**（标识仍在，只是没有可回滚的历史）；
  - 只开自动恢复 → 文件**不**被定时覆盖，**每次手动保存后**记一份快照；
  - 两个都开 → 定时覆盖 + 定时记快照。
- 打开时的提示：未保存过的文档提示"请先另存为"；已保存过的文档提示"可以开启"。

## Consequences

- "手动保存也要记快照"靠**内容变化检测**实现（宿主侧 15 秒重扫 + 每次间隔到点各查一次），而不是靠宿主事件——Word 没有"保存后"事件，`DocumentBeforeSave` 触发时磁盘上还是旧内容。代价是最多约 15 秒延迟。
- 快照文件名用**本地时间**（`yyyyMMdd-HHmmssfff`）便于人工辨认；排序与界面上显示的时间仍以快照里记录的 UTC 为准。
